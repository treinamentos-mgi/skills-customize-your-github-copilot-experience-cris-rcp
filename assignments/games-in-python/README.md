
# 📘 Assignment: Jogo da Forca em Python

## 🎯 Objetivo

Pratique manipulação de strings, loops, condicionais e seleção aleatória ao criar um jogo em que o jogador tenta adivinhar uma palavra oculta.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição
Crie um jogo da forca em que o programa seleciona uma palavra e o jogador tenta descobri-la ao informar letras antes de esgotar as tentativas disponíveis.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras e mostrar as letras descobertas e as posições ainda ocultas, por exemplo, `_ _ _`.
- Acompanhar e exibir o número de tentativas incorretas restantes.
- Encerrar quando o jogador adivinhar a palavra ou esgotar as tentativas.
- Exibir uma mensagem indicando vitória ou derrota.
